Tips that fix most crashes

  1. Update everything. Most crashes are a mod made for a slightly different version.
  2. Check the dependencies. Lots of mods need Fabric API, Cloth Config, or another library mod.
  3. Use the right Java. Minecraft 1.20.5+ needs Java 21. 1.18 to 1.20.4 need Java 17.
  4. Split the mods folder in half. If you can't find the bad mod, remove half and test. Keep halving until you find it.
